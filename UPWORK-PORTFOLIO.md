# Travel Site: Dynamic Price Checker, Technical SEO, GA4 (Next.js 16)

## Project description (≤600 characters)
Responsive travel website built with Next.js 16 and TypeScript for Juragan Travel. Highlights: config‑driven dynamic price checker, route pages with rich FAQs, WhatsApp CTAs, optimized images via Next/Image, and a clean Tailwind UI. End‑to‑end technical SEO (Open Graph/Twitter, canonical, robots/sitemap, JSON‑LD for FAQ/Breadcrumb/ItemList) and GA4 event tracking for measurable results. Designed for speed, discoverability, and conversions.

## Long description
### Overview
I built and optimized a travel website for Juragan Travel using Next.js 16 (App Router) and TypeScript. The focus is performance, technical SEO, and conversions, including a dynamic price checker powered by configuration so fares and routes can be updated without touching code.

### What I delivered
- Next.js 16 + TypeScript architecture (server components and route handlers)
- Responsive, accessible UI with Tailwind CSS (mobile‑first)
- Config‑driven dynamic Price Checker with validation, smooth UX states, and automatic WhatsApp deep links
- Structured route pages with rich content and FAQ to match search intent and strengthen SEO
- Image optimization with Next/Image, fast loading, and Web Vitals best practices
- Full technical SEO: metadata, Open Graph/Twitter, canonical, robots.txt, sitemap, and JSON‑LD (FAQ, Breadcrumb, ItemList)
- Google Analytics 4 integration (pageviews, custom events/conversions) for accurate measurement

### Key features
- Config‑driven intercity price checker (easy fare/route updates)
- Popular route pages with optimized images, clear cards, and strong CTAs
- Structured FAQ (schema.org) for rich results and higher CTR
- SEO‑friendly Header/Footer with improved navigation and title attributes
- Consistent OG/Twitter cards, including dynamic OG image generation

### Stack & tooling
- Next.js 16, TypeScript, Tailwind CSS
- Schema.org JSON‑LD (FAQ, Breadcrumb, ItemList)
- Google Analytics 4 (events and conversions)
- Accessibility and performance best practices (Next/Image, lazy/priority loading)

### Outcomes
- Strong content structure for SEO and rich snippets
- Fast, clear, mobile/desktop friendly user experience
- Streamlined conversion flow via WhatsApp CTAs and forms, fully measured in GA4
