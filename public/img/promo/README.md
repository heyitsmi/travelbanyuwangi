# Folder Gambar Promo

Simpan gambar promo di folder ini dengan format:
- promo-surabaya.webp
- promo-wisata-wali.webp
- promo-grup.webp

## Ukuran yang Disarankan
- Lebar: 1200px
- Tinggi: 800px
- Format: WebP atau JPG
- Rasio: 3:2

## Sementara Waktu
Gunakan placeholder image atau gambar dari layanan seperti:
- Unsplash
- Pexels
- Atau buat dengan Canva

Untuk sementara, sistem akan tetap berfungsi meskipun gambar belum ada.
Next.js akan menangani error gambar dengan baik.
