# Payment Method Logos

Folder ini berisi logo-logo metode pembayaran yang ditampilkan di footer website.

## Format File
- Format: `.webp` atau `.png` (preferensi: `.webp` untuk ukuran lebih kecil)
- Ukuran rekomendasi: Lebar 60-80px, tinggi otomatis (maintain aspect ratio)
- Background: Transparan (untuk logo) atau putih

## Daftar Logo yang Dibutuhkan

### Bank
- `bca.webp` - Logo BCA
- `bri.webp` - Logo BRI
- `mandiri.webp` - Logo Mandiri

### E-Wallet
- `qris.webp` - Logo QRIS
- `gopay.webp` - Logo GoPay
- `ovo.webp` - Logo OVO
- `dana.webp` - Logo DANA

### Tunai
- `cash.webp` - Icon Cash/Tunai

## Sumber Logo
- Download logo resmi dari website masing-masing brand
- Gunakan layanan seperti:
  - [Brand Kit resmi](https://www.bca.co.id) (untuk logo bank)
  - [Brandfetch](https://brandfetch.com) (untuk logo e-wallet)
- Atau gunakan AI generator seperti Midjourney/DALL-E untuk icon cash

## Konversi ke WebP
Gunakan tool online seperti:
- https://squoosh.app
- https://cloudconvert.com/png-to-webp

## Contoh Placeholder
Sementara logo asli belum ada, component akan menampilkan text fallback dengan styling yang sesuai.
